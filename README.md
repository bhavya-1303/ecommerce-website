# 🛒 ShopEasy - E-commerce Website

## 📌 Project Overview
ShopEasy is a responsive e-commerce website developed using HTML, CSS, and JavaScript. It allows users to browse products, search and filter items, add products to cart and wishlist, and place orders.

## ✨ Features

- 🛍 Product Listing
- 🔍 Search Functionality
- 🎯 Category Filtering
- 🛒 Add to Cart
- ❤️ Wishlist
- 🧾 Order Placement
- 🌙 Dark Mode Toggle
- 📱 Responsive Design
